# 显式持续段

observations的slot是零基整数，完整分析轴从最小slot到最大slot，缺slot显式成为missing而不压缩。t=0视为一个新段起点，duration[k-1]为P(D=k)，所有段D>=1且有限；不是平稳过程随机抽到一段中间。状态自身不能转移到自身，持续由duration表达。

exact使用正态密度，interval为P(left<Y<=right)，right为P(Y>left)，missing因子1。完整结束段用P(D=d)，窗口末段只知道覆盖这些已观察时隙，因子P(D>=已见长度)；最后一格之后立即结束与更晚结束不可观测，不重复枚举后续未观察状态。Viterbi的末段可见长度不是声称真实完整长度。

路径决胜先按逐段状态索引序列字典序，再按内部段末slot序列字典序，边界序列不含观测窗末。后验状态按时隙和为1；转移边界后验的和是预期段间转移数而不是1。初始概率、冻结转移和观测参数不会被本次资料重估。

domain只检查参数形状与源观测类别，不进行隐状态推断。
